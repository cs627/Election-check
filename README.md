# 完善選舉制度巡迴互動展覽 — 票箱家族超市 IES Supermarket Quiz

## 遊戲簡介
互動掃碼問答遊戲，配合「完善選舉制度巡迴互動展覽」展覽使用。

## 功能
- 🛒 USB 條碼掃描器支援 + 滑鼠點擊模擬
- ⏱️ 可調整挑戰時間（60-200秒）
- 📋 41條選舉制度 MC 題目（簡單/中等/困難）
- 🎵 倒數音效（最後30秒滴答聲）
- 🏆 排行榜系統
- 📊 Excel 數據管理（非程式人員可更新題目）
- 🎨 9:16 Kiosk 固定版面

## 技術棧
- React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion
- Web Audio API
- XLSX.js
